# Pepper Palace

  A full-stack e-commerce store for buying peppers — built with React + Vite, Express, PostgreSQL, and Drizzle ORM.

  ## Stack

  - **Frontend**: React + Vite, Tailwind CSS, shadcn/ui, Framer Motion, TanStack Query
  - **Backend**: Express + TypeScript
  - **Database**: PostgreSQL with Drizzle ORM
  - **API**: OpenAPI spec with Orval code generation (React Query hooks + Zod schemas)

  ## Features

  - Product catalog with heat-level filtering and search
  - Shopping cart with quantity management
  - Checkout with form validation
  - Order history and order detail pages

  ## Development

  ```bash
  pnpm install
  pnpm run dev
  ```
